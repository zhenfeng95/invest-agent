### 1. 市场状态判断（必须）

#### 市场周期（六选一）

下跌趋势 / 震荡筑底 / 反弹初期 / 反弹确认 / 主升阶段 / 高位风险

#### 判断依据（四块）

1. **上证位置**：相对 MA5 / MA10 / MA20 / MA60
2. **成交量**：两市合计成交额；较前一交易日变化（金额+百分比，能拿到则写）；再比 **近 5 日均量** → 放量/平量/缩量（一句结论即可，勿在 §4 重复）
3. **市场情绪**：涨停/跌停、涨跌家数比；能拿到则写最高连板（一句即可）
4. **主线持续性**：东财和/或同花顺行业（及必要时概念）；双源不一致点明；勿用申万名

#### 市场评分（100 分制）

| 分项 | 满分 | 打分要点 |
| ---- | ---- | -------- |
| 趋势 | 0–25 | 多头/站上均线高分；空头/跌破 MA5·MA20 低分 |
| 量能 | 0–25 | 健康放量且价涨高分；缩量下跌/天量滞涨扣分 |
| 赚钱效应 | 0–20 | 涨停多、跌停少、涨跌比健康 |
| 主线强度 | 0–20 | 主线清晰持续；杂乱轮动/一日游扣分 |
| 风险 | 0–10 | **分越高=风险越可控** |
