| 大盘 / 盘中走势 / 板块 / 宽度 / 技术 | **当日全日**                           | 「今日…复盘」        |

### 1. 市场状态判断（必须）

基于 **当日收盘** 数据判断当前 A 股环境。章节标题：`## 市场状态判断（必须）`。
缺关键数据标「未获取」并下调对应分项与总评置信度；**不编造均线/量能**。

#### 市场周期（六选一，只能选一个）

- 下跌趋势
- 震荡筑底
- 反弹初期
- 反弹确认
- 主升阶段
- 高位风险

#### 判断依据（四块都要写，能拿到的写数字）

1. **上证指数位置**：相对 MA5 / MA10 / MA20 / MA60（站上/跌破/纠缠；能算则算）
2. **成交量**：两市合计成交额 vs **近 5 日均量** → 放量/平量/缩量
3. **市场情绪**：涨停数、跌停数、涨跌家数比；能拿到则写最高连板高度
4. **主线持续性**：用**东财行业和/或同花顺行业**（及必要时概念）描述今日主线是否延续；双源不一致时点明；对齐用户「主线科技/AI」但不硬套；勿用申万行业名

#### 市场评分（100 分制）

| 分项     | 满分 | 打分要点                                                        |
| -------- | ---- | --------------------------------------------------------------- |
| 趋势     | 0–25 | 多头排列/站上均线给高分；空头/跌破 MA5·MA20 给低分              |
| 量能     | 0–25 | 相对 5 日均量健康放量且价涨给高分；缩量下跌/天量滞涨扣分        |
| 赚钱效应 | 0–20 | 涨停多、跌停少、涨跌比健康给高分                                |
| 主线强度 | 0–20 | 主线清晰且持续给高分；杂乱轮动/一日游扣分                       |
| 风险     | 0–10 | **分越高=环境风险越可控**（情绪极端、高位加速、监管冲击等扣分） |

输出固定块：

```
市场评分：XX/100（置信度：高/中/低）
当前状态：<六选一>
对应策略：防守 | 轻仓试错 | 积极参与 | 进攻
操作提示：<三选一完整句：稳→行业主线，买点可激进、个股做小波段；震荡→放弃大盘，关注强势题材，个股高抛低吸；下跌→不适合做主线，题材只宜短打>。
账户重心：<一句；好→国元GY+银河YH进攻；不好→华泰HT+银河YH防守短线>。
```

策略映射：0–40 防守｜40–70 轻仓试错｜70–85 积极参与｜85+ 进攻。
策略须与用户 A 股规则对齐：指数线下偏防守；线上才谈试错/参与；不代选股；不追极端加速。

口诀：**大盘稳、有明显进攻信号和主线 → 做行业主线，买点可以激进，个股做小波段；大盘震荡、没方向 → 放弃大盘，关注强势题材，个股高抛低吸。** 评分块后必须 1 句操作提示。不荐股；不覆盖四选一/止损/只建仓一次。
