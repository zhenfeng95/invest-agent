### A股

买卖核心围绕 **5 日均线 + 趋势线**；最终买卖决策仍由你拍板；Agent **不写荐股清单、不代下单**。

- **一层池（你自理）+ Agent 全量买点分析**：第一层选股由你完成；收盘前把池文件放到 `data/raw/screener/pool-latest.csv`（或对话里指定路径）。Agent **不再代跑公式一层 / 不再代选股**。收盘日报前置对池内**全量**做四选一校验 → 分 **命中 / 未命中** 两表写入日报 **§9「明日值得关注的个股」**（表头含：代码、简称、买点、收盘、MA5、ext、V、MA(V,5)、VR、换手等）。量能按本文「不含当日」；趋势线为自动近似。未交池则 §9 写「用户未提供一层池」。日报板块/资金口径见收盘精简版 prompt。
- **建仓（四选一触发，只建仓一次）**：资金体量小，单标的只建仓一次，不加仓摊薄。买点须四选一命中。已走出一段加速时，优先等回踩，不追加速日。
    - **放量突破 5 日均线**（两类均归入此类）：
        - **首次突破**：昨收 ≤ 昨MA5，今收 > 今MA5，且放量
        - **趋势内放量阳线**：昨收已在 MA5 上方、MA5 向上，今日放量阳线且收盘仍站上 MA5
        - 共性约束：收盘距 MA5 延伸不超过约 **3%**（防追极端加速）
    - 放量突破下降趋势线
    - 缩量回踩 5 日均线
    - 缩量回踩趋势线
- **量能定量（四选一必检；判定当日是否符合买点）**：
    - 记当日成交量为 `V`；`MA(V,5)` = **评估日前 5 个交易日**成交量的简单平均（**不含当日**）
    - **放量**：`V > MA(V,5) × 1.2`（成交量 > 前 5 日均量的 1.2 倍）——用于「放量突破 MA5 / 下降趋势线」
    - **缩量**：`V < MA(V,5) × 0.8`（成交量 < 前 5 日均量的 0.8 倍）——用于「缩量回踩 MA5 / 趋势线」
    - **中间带**（`0.8 ≤ V/MA(V,5) ≤ 1.2`）：量能中性，**不判定为放量也不判定为缩量**；对应买点当日视为未满足量能条件
    - Agent 复盘/校验买点时须写出：`V`、`MA(V,5)`、`V/MA(V,5)` 及是否命中放量/缩量阈值
- **止损**：有效跌破 5 日均线，或有效跌破趋势线 → 止损离场
- **卖出**：同止损逻辑——有效跌破 5 日均线或趋势线即卖；不做复杂分批出货

### 美股（以指数为主）

- **建仓**：碎股买入，按价格阶梯向下加仓（示例：680 买 0.01 股 → 675 再买 0.01 → 670 再买 0.01，每跌约 $5 加一档）
- **卖出**：每上涨约 $5 卖出 0.01 股（对称网格）；或视市场情况改为长期持有、暂不减仓
- **止损**：暂时不设置固定止损（与 A 股严格破位止损形成对照）

### A股

- **单标的回撤容忍**：单只个股最多承受约 **5%** 回撤；触及则按既有止损规则处理
- **组合回撤容忍**：总资金回撤约 **2%** 即需高度警惕 / 减仓
- **持仓数量**：最多同时持有 **3** 只标的；任一标的不满仓
- **行业分散**：3 只标的不得来自同一细分行业
- **总仓位择时**：以上证指数的 **5 日均线 + 趋势线** 为准
    - 指数在线上 → 仓位可偏重
    - 指数在线下 → 仓位偏轻 / 空仓观望
