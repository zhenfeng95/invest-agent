#### 行情 → 账户重心（精力分配）

三账户不全天候同等用力；**随行情好坏切换主战场**（只定心思与精力，不自动代下单）：

| 行情判定 | 姿态 | 账户重心（主） | 降权 |
| -------- | ---- | -------------- | ---- |
| **好**（大盘稳、走趋势，有进攻信号/清晰主线；§1 策略偏积极参与或进攻） | 主做**进攻** | **`GY` 国元 + `YH` 银河** | `HT` 华泰（指数仓维持即可，不把精力堆在指数微调上） |
| **不好**（大盘震荡没方向，或不稳下跌；§1 策略偏轻仓试错或防守） | 主做**防守 + 短线** | **`HT` 华泰 + `YH` 银河** | `GY` 国元（四选一谨慎仓少开新、少盯） |

- **`YH` 银河两端都在**：行情好时跟进攻尾盘；行情不好时跟短线/高抛低吸，是常驻账户。

#### 账户 1 · `GY` 国元证券（谨慎 · 四选一）

买卖核心围绕 **5 日均线 + 趋势线**；偏谨慎；**本文「风险偏好 · A股」中的单票/组合回撤、最多 3 只、行业分散、上证择仓，默认只约束本账户**。

- **一层池（你自理）+ Agent 全量买点分析**：第一层选股由你完成；收盘前把池文件放到 `data/raw/screener/pool-latest.csv`（或对话里指定路径）。Agent **不再代跑公式一层 / 不再代选股**。收盘日报前置对池内**全量**做四选一校验 → 分 **命中 / 未命中** 两表写入日报 **§7「明日值得关注的个股」**（表头含：代码、简称、买点、收盘、MA5、距MA5、V、MA(V,5)、V / MA(V,5)、换手等）。量能按本文「不含当日」；趋势线为自动近似。未交池则 §7 写「用户未提供一层池」。日报资金/板块口径见收盘精简版 prompt（**§4 资金与板块共振**）。
- **建仓（四选一触发，只建仓一次）**：资金体量小，单标的只建仓一次，不加仓摊薄。买点须四选一命中。已走出一段加速时，优先等回踩，不追加速日。
    - **放量突破 5 日均线**（两类均归入此类）：
        - **首次突破**：昨收 ≤ 昨MA5，今收 > 今MA5，且放量
        - **趋势内放量阳线**：昨收已在 MA5 上方、MA5 向上，今日放量阳线且收盘仍站上 MA5
        - 共性约束：收盘距 MA5 延伸不超过约 **3%**（防追极端加速）
    - 放量突破下降趋势线
    - 缩量回踩 5 日均线
    - 缩量回踩趋势线
- **量能定量（四选一必检；判定当日是否符合买点）**：
    - 记当日成交量为 `V`；`MA(V,5)` = **评估日前 5 个交易日**成交量的简单平均（**不含当日**）
    - **放量**：`V > MA(V,5) × 1.2`（成交量 > 前 5 日均量的 1.2 倍）——用于「放量突破 MA5 / 下降趋势线」
    - **缩量**：`V < MA(V,5) × 0.8`（成交量 < 前 5 日均量的 0.8 倍）——用于「缩量回踩 MA5 / 趋势线」
    - **中间带**（`0.8 ≤ V/MA(V,5) ≤ 1.2`）：量能中性，**不判定为放量也不判定为缩量**；对应买点当日视为未满足量能条件
    - Agent 复盘/校验买点时须写出：`V`、`MA(V,5)`、`V/MA(V,5)` 及是否命中放量/缩量阈值
- **止损**：有效跌破 5 日均线，或有效跌破趋势线 → 止损离场
- **卖出**：同止损逻辑——有效跌破 5 日均线或趋势线即卖；不做复杂分批出货
