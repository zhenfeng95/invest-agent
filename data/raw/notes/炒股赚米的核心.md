## 市场本质

股票是一场**人性的游戏**：随机、波动、不确定、不稳定。  
承认不确定性，才谈得上纪律与模式。

---

## 胜于易胜：只在容易赚钱的时候交易

总原则：**只做顺风局**——市场秩序未重建时，宁可空仓，不做难做的行情。

### 判断大势（做多前须具备）

1. **指数先企稳**  
   - 出现上涨阳线  
   - 站稳 **5 日、10 日均线**  
   - 突破下降趋势线  
2. **主线明确**  
   - 有板块领涨，形成资金做多的载体  
   - 主线有**延续性**（不是一日游）  
3. **右侧出现**  
   - 肉眼能看到底部结构时，至少要有一个**底分型**  
   - 有底分型，才考虑**加法**（加仓/开仓），左侧抄底不算

### 多头共振（四件事一起出现，才看多做多）

| 条件 | 含义 |
|------|------|
| 板块领涨 | 主线清晰、有资金载体 |
| 指数上涨 | 大盘配合，不是逆势孤岛 |
| 红盘家数增加 | 赚钱效应扩散 |
| 板块联动上涨 | 不是单票乱舞，秩序在重建 |

> **板块领涨 + 指数上涨 + 红盘家数增加 + 板块联动上涨** → 市场秩序重新建立 → 才可以看多做多。

### 潮汐与心态

- 顺手时不骄傲；逆风时不悲观。  
- 交易成长不在顺境高歌，而在**逆境守住节奏**。  
- 别在下跌中急于证明自己；别为了抢反弹丢失原则。  
- 市场如潮汐：有高歌猛进的涨潮期，就有泥沙俱下的退潮期——**退潮期少做或不做，涨潮期再出手**。

## 九条总纲

1. **一招鲜做到极致**（成名绝技）——方法少，练到极致。
2. **只在正确的方向下注**——方向不对，不做。
3. **自律自建赚米模式**——锚定：趋势 · 波段 · 涨停 · 龙头。
4. **专注自留地**——价值 / 成长 / 稳健，不东打西打。
5. **过回撤关**——执行力 + 交易纪律；迈不过回撤，谈不上盈利。
6. **盈亏心态分水岭**  
   - 盈利的人：心思在**避免亏损**  
   - 亏损的人：心思在**追求盈利**
7. **自律 · 心态 · 自愈力**  
   - 改掉重复犯错的习惯  
   - 大道至简：**持赢止损**  
   - 亏损股卖出速度 ≈ 盈利股的 **2 倍**（亏得快走，赚得拿住）
8. **最难的不是买，而是拿住**——在剧烈波动与质疑中，怎样继续持有正确的仓。
9. **少即是多**  
   - 模式多 → 选择混乱  
   - 买点多 → 操作随意  
   - 卖点多 → 决策摇摆  
   - 品种多 → 选择盲目  
   - **方法越繁多，交易越随机**  
   - 对策：**简单重复 · 一招鲜**

## 买点体系（与 5 日线 / 趋势对齐）

### 大原则

- **线上买**：5 日均线上方、趋势向上才买
- **贴线**：贴 5 日均线 / 贴趋势线 → 低吸窗口
- **远离**：远离 5 日均线 / 远离趋势 → 慎重（易变成追高）
- **蓄势**：小形态、盘整后等待

### 盘整与方向概率（笔记口径）

- 盘整常见演化：约 **15% / 15% / 70%** 一类分布；约 **85%** 会继续盘整（解读：多数时候横着走，别急着猜突破方向）
- **买下降趋势**：亏的概率 **≥80%** → 不做
- **上升趋势里收阴**：常视为买点（回踩类）

### 买的条件口诀

**有钱 · 有动能 · 有优势 · 有趋势 → 顺势 · 借势**  
要买，就按既定买点 **1 / 2 / 3** 执行（不临时发明买点）。

> 笔记原话气质：方向对时「100 次买 99 次对」——强调的是**只做上升趋势**，不是吹嘘胜率神话。

### 两类主买点

| 类型 | 细分 |
|------|------|
| **低吸** | 上升趋势低吸；贴线（MA5/趋势线）低吸 |
| **突破** | 突破下降压制；突破平台 |

笔记自评口径：做对上述体系时，约 **90%** 偏赚钱环境（仍须止损纪律托底）。
