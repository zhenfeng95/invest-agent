## 系统总框架（执行顺序）

1. **选股**（有钱优势 / 池子）
2. **判断大盘**（决定仓位）
3. **找买点**（确认信号）
4. **分批建仓**（金字塔）
5. **持仓管理**（看趋势、量能）
6. **卖点**（止盈 / 止损）

核心分工：**大盘管仓位，个股管买卖**。分析大盘与行情运行轨迹；大盘调整负责仓位，个股负责买卖。

## 一、仓位风控：按大盘状态加减仓

目标：学会加减仓，规避大盘系统性风险，提供稳健交易大环境，为仓位和交易策略提供信息。

### 1. 大盘不稳定 / 下跌（无明显进攻信号与主线）

| 维度 | 规则 |
|------|------|
| 仓位 | **20% 或空仓** |
| 策略 | 快进快出，以回本为主，不强制盈利 |
| 空间 | 目标往小看 |
| 卖点 | 到压力位就走；第一目标卖一半，留一半平本，拿未来大行情 |
| 姿态 | **以防守为主，保住本金** |
| 环境 | 指数在 **5 日、10 日均线之下**；可做概念题材短线 |

防守工具（**ETF 基金**为主：短线套利；偏离均线建仓，或到达前期支撑建仓；个股慎用）：

- 月线 KDJ 测底 → 分批分段买入；行情差则挂单间距拉大
- 反弹盈利可先出，再低挂，重复降低成本
- 买点参考：KDJ / K 线支撑 / 反弹（短线）与反转（趋势）；月周日撞底可参考；低吸、顺势、突破、KDJ 底背离

### 2. 大盘震荡 / 有上冲机会

| 维度 | 规则 |
|------|------|
| 仓位 | **30%～50%** |
| 策略 | 短线抢单；放弃大盘，盯强势板块 |
| 空间 | 第一目标位清仓 |
| 手法 | 个股高抛低吸 |

### 3. 大盘稳定向上（有进攻信号与主线）

| 维度 | 规则 |
|------|------|
| 仓位 | **60%～80%+** |
| 策略 | **敢拿是核心**；短线 + 小波段 |
| 空间 | 往大空间看 |
| 卖点 | 第一主空间减仓；第二主空间可清仓，或无风险信号不卖 |
| 姿态 | **以进攻为主，顺势赚钱** |
| 环境 | 指数在 **5 日、10 日均线之上**；做**行业主线** |

**如何判断「稳定向上」**：起涨信号（如横盘突破）后尚未出现风险信号；行情上涨且未见顶。

**买点可偏激进**：

- 追涨型：不等回落，看小周期结构入场
- 埋伏型：到位就买
- 确认型：顾比、包含、形态 ABCD、横盘突破

> **胜于易胜，只在容易赚钱的时候交易。**

## 二、选股

### 1. 先选热点板块（赚钱效应所在）

每日观察；加入板块池。

**主线标准**：有涨停才有人气；有涨幅才有广度；**两者兼备才是主线**。

| 步骤 | 做法 |
|------|------|
| 定性 | 用**板块涨停数**找主线：梯队完整（≥2 只），有龙头 / 中军 / 跟风；有持续发酵潜力与板块容量；有政策或事件逻辑；跌停少（资金未撤退） |
| 定量 | 用**板块涨幅榜**验证强度 |
| 趋势 | 大盘涨 → 找同频板块（均线 + 结构）；大盘调 → 指数对比找抗跌板块 |

- 短线：偏**概念 / 题材**，紧跟最强热点  
- 波段：优先概念、兼顾行业，交叉验证共振  
- 用**趋势结构**定大方向（滞后低、易早发现转折），用**均线**确认买卖点  

### 2. 板块内找潜力股

模型：**成交额为核心 → 换手率为过滤 → 涨幅为验证**。

排序权重：成交额 > 换手率 > 涨幅。

- 成交额：代表资金，保障流动性与关注度，是稳健趋势的「生命线」
- 换手率：情绪过热/过冷的「健康度检测仪」
- 涨幅：结果，而非先行决策依据

公式直觉：

> 大资金（成交额）+ 健康换手（筹码稳）+ 顺势位置（均线支撑）= 高胜率稳健趋势

硬过滤（导图口径）：

- 成交额 **> 3 亿**
- 换手率 **2%～15%**
- 量比 **≥ 1.2**，量能逐步放大，有堆量更好

重点三类：有启动买点信号；成交放量异动；大阳放量、调整缩量。

> 趋势是方向，资金是动力，节奏是低吸；找准主线，控制风险。

### 3. 月初至今涨幅选股法

- **月初至今涨幅**约在 **5%～15%**
- 成交额 **> 3 亿**
- 顺势逢低买进

## 三、建仓 / 平仓路线（成功路径）

1. 试错：一成仓位，买一点  
2. 分仓：两三只股票  
3. 谨慎跟踪、观察、分析  
4. 分批分段分次；可高抛低吸降成本  
5. 留强去弱：弱的调仓 / 轻仓，强的按趋势持有、可分批加仓  
6. 仓位低时合理分散去弱；仓位高时绝对集中、重仓吃透；减少交易频率  
7. 可按周反复布局；先稳住不亏，再找赚钱节奏

## 四、买点内参

先建股票池，每天观察，伺机出手。参考：均线、周期位置。

### 短线（约 20% 资金）

一次性交易，做惯性；可用尾盘选股。心态：**别追高、别冲动；宁可错过，不可做错**；小资金试盘练盘感。关注狙击时机与机会。

| 买法 | 要点 |
|------|------|
| 10 日线回踩（最稳） | 沿 MA5 陡峭上行时，小幅回调是机会；5 日与 5 周均线都向上更佳 |
| 5 日金叉 10 日 | 启动确认；10 日至少走平或向上 |
| 60 分钟：5H 金叉 20H | 精确入场 |
| 阳线后阴线调整 | 顺势下，收盘突破前阳最高价为买点 |

### 小波段（约 80% 资金，核心仓）

选股可用「月初至今」+「主力擒牛」。研究突破、支撑、压力、趋势；工具：**5 / 10 日线 + 趋势线**。要求：上涨有力度、回调有支撑、结构不断创新高。趋势线多画，线与线互联。目标：高胜率 + 高盈亏比。

| 类型 | 做法 |
|------|------|
| ① 突破买 | 破下降趋势线或破 5 日线 → 试仓；跌破出；破平台 / 小头部 → 加仓 |
| ② 线上买 | 5 日线 / 趋势线上买；贴线低吸、阴线买；破 5 日或趋势线先出，突破再入。贴线形：**多数对，最后一次错**（止损纪律） |
| ③ 中大阳后低吸 | 消化完前一波涨幅再起下一波时低吸，**不是拉升途中追**；破中大阳低价出 |
| ④ 上升通道支撑 | 缩量回踩买入：优先回踩 **20 日**；或缩量回踩 M10 / M20 / 趋势线后拐头；顾比买点；可建底仓 |
| ⑤ 上升中继（追涨式） | 10 日金叉 20 日；看多空力度（K 线强弱）；大阳/中阳反包大阴/中阴、长上影、十字星；小横盘突破；大阳回踩；加仓确认 |
| ⑥ 新趋势形成 | 放量破下降通道 / 阶段新高 / 震荡平台或颈线 → 随后缩量回踩平台顶获支撑时跟 |

**量 · 价 · 线 · 势 四确认**：

| 维度 | 标准 |
|------|------|
| 量价 | 上涨放量、下跌缩量；涨日量明显大于跌日量（缩量回调 = 抛压轻、筹码稳） |
| 位置 | 趋势线之上，或 10 / 20 日均线之上（20 日=中期生命线） |
| 结构 | 高点更高、低点更高；回调不破前低（上涨强、下跌弱） |
| 趋势 | 多头排列、均线向上发散（角度越陡越强） |

- 建仓：**343 建仓法，最多建仓 3 次**  
- 进可攻退可守：未到支撑就启动 → 过掉前期压力再入；跌到支撑且出买点信号 → 入场  
- **永远买不在最低点**；挣的是机会形成后的空间  
- 波段终极目标：一击必中、重仓大赚  
- 有支撑看支撑（不跌破）；有压力看压力（要突破）  

> 低吸 = 消化完前一波涨幅、准备起下一波时；不是拉升过程中。

## 六、止损风控

### 单票（第一步）

| 级别 | 规则 |
|------|------|
| 短线止损 | **3%～5%** |
| 波段止损 | **5%～7%**（行情差用 5%） |
| 预警 | 亏约 **3%** → 减仓，先减不好的 |
| 清仓 | 约 **5%** → 全部清仓 |

### 整体资金（第二步）

- **3～5～7%** 阶梯；基本到 **5%** 应已清仓完毕  
- 控制总回撤是根本：降仓 / 空仓，并复盘找问题  

### 亏损之后做防守（第三步）

亏后转入防守节奏，不急于翻本。

### 冲突时优先级

> 单票止损比例 vs 总资金快速回撤冲突时，**以先卖出为主**——总资金别往下掉；慢增长可以，稳定优先。

### 心法（导图原文要点）

- 交易笔记：乘势而起，待时而动；低吸高掷，游刃于波段之隙；张弛有度，决胜于毫厘之间  
- 截断亏损，让利润奔跑；复利核心是控制回撤  
- 优质标的敢重仓吃透主升浪 → 大赚小亏  
- **赚钱时控制回撤，亏钱时止损出局**  
- 顺手不骄、逆风不悲；成长在逆境守节奏  
- 市场如潮汐：退潮少做，涨潮再出手

## 八、每日复盘

### 复盘指数

总结口诀：**大盘搭台，小票唱戏；权重稳情绪，成长走空间**。

| 指数 | 角色 |
|------|------|
| 上证 | 传统权重；大盘稳则人心稳，大跌易带崩好票 |
| 沪深300（000300） | 全市场最大 300 家；整体强弱风向标 |
| 创业板（399006） | 成长、弹性、情绪热度 |
| 科创板（导图标注 000680） | 硬科技、波动大；前沿与大资金方向 |

健康度速判：

- 上证与沪深300同涨 → 市场较稳，可积极关注  
- 大盘涨但沪深300 / 科创 / 创业板中有 2 个下跌 → 上涨不健康  
- 大盘/沪深300跌 → 情绪走弱，成长板易被带崩；成长板强也可反托大盘  

另复盘：**板块**；**涨跌停个股**（情绪传递、主线强弱、资金进退）。

### 调整与见底

| 调整方式 | 特征 |
|----------|------|
| 下跌式 | 空间大、时间短，以空间换时间 |
| 横盘式 | 时间长、跌幅小，以时间换空间 |

1. 放量下跌后 → 缩量下跌 + 十字星或小阴小阳，且不破新低；无顾比结构则只做小短线反弹  
2. 大阳反包放量下跌阴线的最高价

## 九、交易策略：大盘三态（策略篇）

### 大盘上涨

- **势不尽，顺不止**  
- 「势」= 上涨力度 + 有无风险信号  
- 风险信号阶梯：分时分歧（预警）→ K 线风险（高开低走、长上影，积极调仓）→ 下跌趋势形态（小范围操作，多等待）→ 破支撑打开下跌空间（休息）  
- 板块：模型 + 指标找刚启动 / 已上涨板块  
- 个股：已大涨放弃；刚起涨做短线；蓄势出买点做波段；未蓄势放入二梯队  
- 生命线：短线看 **5 日**，小波段看 **10 日**  

### 大盘调整

识别：上涨疲软、下跌发力；涨家锐减；光涨指数不涨个股；炸板频现；关键支撑连续破位；轮动极快无主线、防御板块凸显。  

- 指数对比 + 模型找强势板块  
- 个股风险永远优于指数；设二级跟踪：**减仓点 / 清仓点**  

### 大盘下跌（轻仓）

1. 到支撑 → 盯启动信号；看涨跌家数（该涨不涨则弱）  
2. 首次启动（如大阳吞没）→ 主线轻仓约 **20%**；看板块能否维持、指数能否过下一关  
3. 过前期压力 → 主线明确时寻找操作  
4. 形成上涨进攻结构后再加码  

**多头共振（做多前）**：

1. 指数企稳：阳线 + 站稳 5/10 日 + 破下降趋势线  
2. 主线明确且有延续性  
3. 右侧底分型后再考虑加法  

> 板块领涨 + 指数上涨 + 红盘家数增加 + 板块联动上涨 → 秩序重建 → 才看多做多。

**仓位阶梯总结**：

| 大盘状态 | 动作 |
|----------|------|
| 不动 | 我们不动 |
| 到支撑 | 重点关注 |
| 出现买点信号 | 强势板块轻仓约 **20%** |
| 过压力 / 进攻信号 | 波段关注，仓位约 **50%** |

## 十、分析篇（导图案例：2025-09-24）

1. **触压回落**：到游资雷区后向下回落，回落不破临近上涨的潜2 支撑 → 有启动信号可先做短线；一旦跌破全部清仓；再次启动形成 ABCD 上涨模型后，回调下来加重仓位，随行情演变慢慢加仓

价格跌破潜2 → 市场重新进入弱势，中短期全面减仓；跌破后前期低点支撑弱，易形成新的 ABCD 下跌；此后反弹至游二 / 平高易砸盘，空方较强。

   - 潜2 不破且形成新 ABCD 上升 → 新一轮重要上涨，仓位加到 **50% 以上**  

### 若把当前行情当个股（方法迁移）

- 若直接突破游二 → **不追不加仓**；形成 ABCD 大结构后，等回调再做

- 若虚晃一枪跌破潜2 → **清仓该股**（大盘则全线减仓到 20% 以下），避免走下跌 ABCD；求稳可不急加仓，等形成 ABCD 结构后再回调加仓

## 十一、势能检查清单（开仓前自检）
