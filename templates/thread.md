# Thread 模板

## 结构（建议 5–8 条）

| 序号 | 作用 | 要点 |
|------|------|------|
| 1 | 钩子 | 承诺价值：读者读完能带走什么 |
| 2 | 背景 | 为什么现在重要（1–2 句） |
| 3–N | 论证 | 每条只讲一个点；数据 + 来源 |
| N+1 | 综合判断 | 你的结论与置信度（高/中/低） |
| 最后 | CTA | 提问 / 关注点 / 风险提示 |

## 写作规则
- 每条可独立阅读，但串联成完整叙事
- 避免"首先/其次/总之"；用数字或短标题分隔
- 关键数字用粗体或单独成行（按平台能力）
- ticker 大写；引用标注来源与时间

## 输出格式

```
1/ [钩子]

2/ [背景]

3/ [论点 A + 数据]

4/ [论点 B + 数据]

5/ [论点 C 或反方观点]

6/ [综合判断 | 置信度：中]

7/ [互动问题]

⚠️ 不构成投资建议
```

## 自检清单
- [ ] 第 1 条让人想点开
- [ ] 每条 ≤ 平台字数上限
- [ ] 有数据支撑，非纯情绪输出
