# 收盘推文模板（X · 主贴 + 3 条回复）

> Automations：收盘日报写完后 **立即** 按本模板生成当日推文；飞书只推 **主贴**。  
> 样例节奏见：`output/content/tweet-2026-09-10-us-close.md`、`tweet-2026-09-10-ashare-close.md`

## 文件路径

| 市场 | 路径 |
|------|------|
| 美股 | `output/content/tweet-YYYY-MM-DD-us-close.md`（YYYY-MM-DD = 北京日期 = 日报文件名日期） |
| A股 | `output/content/tweet-YYYY-MM-DD-ashare-close.md` |

## 硬约束

- **主贴首行标签（无国旗）**：`美股收盘｜M/D` 或 `A股收盘｜M/D`（M/D = 复盘交易日，如 9/9）
- **主贴叙事密度（对齐美股样例）**：禁止「指数+宽度+一句策略」干巴堆砌。必须含：
  1. **钩子 1 句**：反直觉定性（不是单纯跌 / 不是回踩 / 不是普涨里藏弱…）
  2. **结构 1–2 句**：相对强弱、内部分化、主线有无
  3. **流向/主题 1 句**：谁强谁退 + 关键涨跌数字
  4. **盯什么 + 判断 1 句**：下一验证点 + 策略档（防守/轻仓等）
- **公开用词**：成交额/涨跌家数对外写 **「全市场」**，不写「沪深京」「两市」（底层仍含北交所；拆分明细留日报）
- **前100**：推文写 **「全市场成交额前100」**（或「成交额前100」），禁止只写含糊的「前100」
- **回复 ×3**：结构 / 宏观或资金 / 判断；**每条 X 加权 ≤280**（中文约按 2 计）；保留关键对比数字，删重复解释
- **禁止私域口径（硬规则 · A股+美股通用 · 主贴+全部回复）**：
  - **不得**出现个人持仓解读（代码/简称/浮盈/破 MA5/止损等）
  - **不得**出现账户体系话术（`HT`/`YH`/`GY`、账户重心、某账户降权等）——浏览者不懂
  - **不得**出现私域评分编号口吻（如「评分27→…」）；可写公开可读的市场姿态（偏防守/不宜追等）
  - 持仓与账户重心只留在 `output/daily/` 日报，**不进 X / 不进飞书主贴**
  - 可写市场级龙头/板块代表作结构论据；判断段从**宏观/市场结构**给姿态，不写「我的仓/我的账户」
- **缺数据不展示（硬规则 · A股+美股通用）**：某指标拿不到就**整句省略**；**禁止**在推文写「未获取」「暂无可靠数据」「502」「接口失败」等元话术（例：禁止「东财主力净额502未获取」）。有涨跌可写涨跌推断；无则跳过该维
- **禁用**：荐股清单、稳赚暗示、emoji 堆砌、hashtag 堆砌
- 文末固定：`个人复盘，非投资建议。`
- 数字必须来自刚写完的当日收盘日报；不编造
