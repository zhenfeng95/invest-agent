# 推文模板

## 结构
1. **钩子**（1 句）：抛出反直觉观点 / 尖锐问题 / 关键数字
2. **论据**（2–4 句）：事实 + 数据，注明来源
3. **判断**（1 句）：你的解读（interpretation），与事实区分开
4. **收尾**（可选）：提问互动 / 风险提示

## 约束
- 单条建议 ≤ 280 字符（英文）或约 140 汉字（中文平台可更长，仍保持紧凑）
- ticker 大写；数字带单位
- 不堆砌标签；最多 1–2 个相关 hashtag（按用户习惯）
- 风格对齐 `data/raw/tweets/` 与 `my-soul.md` 其他补充

## 输出格式示例

```
[钩子]

[论据一句]。[数据 / 来源]

[判断]

#可选标签
```

## 自检清单
- [ ] 有明确观点，不是复读新闻标题
- [ ] 事实与解读已区分
- [ ] 语气像用户本人，不像研报摘要
